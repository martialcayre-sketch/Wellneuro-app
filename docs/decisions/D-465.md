**§1 — Le lien d'axe.** Le lien `bal_f79_04` (`BIO_ANTI_LDL_OXYDE` →
`stress_oxydant`, fondé sur `WN-CL-0161-070`) passe à `actif = false` ; la
ligne reste, pour l'historique. Le code ne lit que les liens actifs
(`catalogue.ts`) : la Bibliothèque n'affiche plus d'axe pour ce marqueur.
Motif, relu contre le passage source et contre `WN-CL-0647-002` : le claim
applique à l'autoanticorps dosé par le catalogue une lecture qui vaut pour un
autre objet mesuré ; l'inférence vers l'axe n'est pas étayée. Le texte du
motif est consigné sur la surface privée et le sera dans l'atelier.

**§2 — Les panels.** Le marqueur sort de `PANEL_NEURODEG_1` (rang 5,
`BIO-NEU-01`) et de `PANEL_METABOLIQUE_1` (rang 7, `BIO-MET-01`) ; les
autres items gardent leur rang. Le courrier au médecin et le document patient
recalculent la proposition à chaque émission depuis la composition des
panels en base (`propositionService.ts`) : les prochains ne demandent plus le
marqueur. Les documents déjà émis restent inchangés en archive. Le maintien
de `WN-CL-0167-023` et `WN-CL-0178-054` vaut pour les autres analyses de
leurs panels, pas validation du marqueur. Le contrat
