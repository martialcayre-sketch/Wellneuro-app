**§1 — Une dose du registre des compléments passe par un claim ou une
position signée** (`20261113-1338-c`). [[D-480]] §4 nomme quatre sources de
dose. Le format livré par la PR 3 (#2006) en cite deux formes : un claim
certifié `WN-CL-NNNN-NNN@vN.M` et une position d'expert signée
`WN-PE-NNNN@vN.M`. Un référentiel externe ingéré l'est en claims, qui se
citent déjà. Le registre des compléments n'a pas de forme de renvoi, et
**n'en reçoit pas** : une dose qu'il porte est d'abord portée par un claim
certifié ou par une position d'expert signée du responsable, et c'est ce
claim ou cette position que la bibliothèque cite. Le format, le contrat de
fraîcheur et le contrat des positions ne changent pas. La transcription des
contenus (PR 7) compte cette étape de plus.

**§2 — `information_manquante` dans toute rubrique sauf les précautions**
(`20261113-1339-c`). [[D-480]] §5.2 distingue une rubrique « non portée »
d'une rubrique « déclarée manquante ». Le format les écrit désormais
toutes deux, dans chacune des huit rubriques autres que les précautions :
- une liste vide = **non documentée** ;
- `information_manquante`, seul = **déclarée manquante**, jamais une
  valeur (DC-01) ;
- `information_manquante` avec une source = **incohérent** (la structure
  ne se signe pas).

Les précautions ne se déclarent pas manquantes : vides ou
`information_manquante`, la structure est incohérente ([[D-480]] §5.1,
DC-38). BP-18a jugera, sur ces deux états, si une option est exécutable.

**§3 — Mise en œuvre.** `RUBRIQUES_INFORMATION_MANQUANTE`
(`web/src/lib/bibliotheque-options/vocabulaire.ts`) passe de la dose seule
à toutes les rubriques sauf les précautions ; le banc
`bibliothequeBesoin2V1.test.ts` le tient, rubrique par rubrique. Rien en
base : les tables de la PR 2 ne connaissent pas les renvois.
