# D-483 — Portail patient dès 1 024 px : le rail seul ; plus d'onglets dans l'en-tête, « Autres espaces » non rendu sur le hub quand le rail est servi (amende D-460 §3 et D-447 §2)

- Date : 2026-11-11
- Statut : accepté mot pour mot par le responsable le 2026-11-11, dans le
  bloc validé décrit à [[D-481]] (amendement AM-2 de l'étape 2, « tel que
  rédigé »). Réponse 3 (a) de l'étape 1 et sa précision : « Lorsque le rail
  est escamoté, une commande "Menu" doit permettre de retrouver toutes les
  destinations autorisées ». Texte rédigé par l'assistant ; les renvois
  internes du dossier sont remplacés par les numéros de décision.
- Domaine : portail patient, `web/src/app/portail/layout.tsx`,
  `web/src/components/patient/barre-basse/VuesRapidesPortail.tsx`,
  `web/src/components/patient/autres-espaces/`, la page du hub. Lot PAT-1.
- Nature : décision d'écran, non clinique.
- **Amende** [[D-460]] §3 (onglets de l'en-tête) et [[D-447]] §2 (« Autres
  espaces reste sur le hub à toute largeur », Q60).
- **Ne change pas** : la barre basse sous 768 px ([[D-444]]), le bouton
  « Menu » de 768 à 1 023 px, « Autres espaces » sous 1 024 px ; les icônes
  de [[D-460]] §2 et leur drapeau.

**§1 — [[D-460]] §3 (amendé).** L'en-tête ne porte plus d'onglets. Dès
1 024 px, sur les pages du rail, le rail est la seule navigation « Mon
espace » ; la barre basse reste sous 768 px.

**§2 — [[D-447]] §2 (amendé, Q60).** Sur le hub, dès 1 024 px, quand le
rail est servi, « Autres espaces » n'est pas rendu : il répétait la liste du
rail. Rail escamoté, la liste complète se retrouve par le bouton « Menu »
([[D-482]] §2). Sous 1 024 px, ou si la garde du rail refuse, « Autres
espaces » reste sur le hub, inchangé.

**§3 — La frise.** La frise du hub (`FriseEtapesNavigable`) reste ; elle
montre les étapes du parcours, pas les espaces. Le catalogue Lien v2 §5.3
gardait les onglets : écart assumé, consigné au catalogue révisé de
l'étape 2.

- Conséquences : paragraphes d'amendement dans [[D-447]] et [[D-460]] ;
  fragment `changelog.d/2026-11-11-refonte-lien-doc0.md`.
