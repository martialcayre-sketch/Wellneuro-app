# D-307 — Document pour le médecin : l'impression laisse une ligne datée au Fil ; le patient le remet lui-même ; rien ne part vers un tiers (lettre q)

- Date : 2026-10-15
- Statut : accepté. Fond acquis : séance du 2026-10-11 (« sous garde et
  trace », « remise au patient tracée, aucun canal tiers ») ; geste tracé
  choisi le 2026-10-15, sur question à options (« Impression seule »,
  recommandé, contre « Aperçu et impression »).
- Domaine : page Documents du praticien
  (`web/src/components/patient-cockpit/DocumentsPanel.tsx`), rendu sous
  `assertRenduMedecinNonPrescriptif` ; Fil de correspondance ; remise de la
  lettre d'adressage ([[D-262]]) comme patron ; fiche F38.

**§1 — Garde.** Le document pour le médecin reste sous la garde non
prescriptive.

**§2 — Trace.** « Imprimer » demande une confirmation, puis écrit au Fil
« Document pour le médecin imprimé le … ». Ouvrir l'aperçu pour relire ne
laisse pas de trace.

**§3 — Remise.** Le patient télécharge « Pour votre médecin » dans son
portail et le remet lui-même ; le téléchargement est journalisé, comme la
lettre d'adressage. Rien ne part vers un tiers.

**§4 — Portée.** La signature du praticien ne qualifie rien. Tout envoi
direct vers un tiers est un déclencheur de [[D-286]] §2.

**§5 — Exécution.** J2-med : rang 1 si la trace tient dans le Fil existant,
sinon rang 4 avec sa migration.

**Amendement (2026-10-18, F38).** Arbitrages du responsable, sur questions à
options :
- la trace est une table neuve : l'instantané FIGÉ de chaque impression
  confirmée (`documents_medecin_imprimes`) ;
- chaque téléchargement est une ligne datée (`telechargements_documents_medecin`) ;
- le patient reçoit la DERNIÈRE impression ;
- conservation : la vie du dossier ;
- l'impression est refusée si le partage avec le médecin traitant est refusé,
  retiré ou jamais exprimé (règle de la correspondance médecin) ;
- **§3 précisé** : après un refus, un retrait ou un silence, le portail ne
  propose plus le document, et un accord redonné le rend. Cette exception à la
  règle « un document reçu par le patient n'est pas gardé par ce choix »
  (`lib/trust/consentementPartage.ts`) a été maintenue en connaissance de
  cause : ce document n'existe que pour être remis à un médecin ;
- l'impression tracée est servie dès le déploiement ; le portail est derrière
  `WN_DOCUMENT_MEDECIN_PATIENT`.

Compléments du 2026-10-19 :
- les textes du portail sont validés tels quels ;
- une synthèse imprimée pour le médecin ne se vide ni ne se rejette, comme
  après l'envoi du booklet ; pour corriger, une nouvelle synthèse imprimée
  remplace l'ancienne pour le patient ;
- portail ouvert, la confirmation d'impression annonce : « Le patient pourra
  le télécharger dans son espace pour le remettre lui-même. »
