# LOT-02 — Finalisation de l’UI praticien et intégration au parcours

## Objectif

Faire du rayon compléments un parcours utilisable et cohérent côté praticien, sans dépasser le périmètre déjà engagé dans le dépôt.

## Travaux

- vérifier l’état du panel de rayon et de la fiche complément ;
- confirmer la cohérence entre l’UI et les réponses API ;
- identifier les points de friction restant avant activation réelle.

## Critères de fin

- l’UI est cohérente avec les données servies ;
- les parcours d’utilisation principaux sont documentés ;
- les limites d’activation sont explicites.
