date de bilan illisible ou postérieure à la référence concluait
`deja_documente`, donc RETIRAIT le panel. La garde jumelle du service est

## Ce que la revue a changé (NO-GO → GO)

Les trois blocages tombaient **dans le périmètre revendiqué comme soldé** —
d'où le choix de les traiter, pas de les reporter :

- `key={idPatient}` était posé sur `ClinicalRuntimeSection`, alors que c'est

  sur la plus grande sous-arborescence ; la clé est remontée au point de
  montage.
- Le repli rouvrait **deux silences** : panel discordant (sortie en `continue`
  avant le motif) et panel sans ligne. Le second remonte désormais par
  `declarationsIgnoreesHorsProposition`, que l'écran affiche.
- La matrice portait **deux définitions concurrentes** d'« import de type » ;
  `import { type X }` seul restait compté. Un juge unique (`nomsDeValeur`) les
  décide, et un banc éprouve que les deux chemins ne divergent pas.

Trois corrections mineures dans la même passe : le courrier nomme les rapports
calculés, le moteur adopte la **même** tolérance de fuseau que la route, et le
motif distingue une date de déclaration illisible d'une date de RÉFÉRENCE
illisible.
