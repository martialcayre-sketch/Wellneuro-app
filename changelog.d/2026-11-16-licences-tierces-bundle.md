### Mentions de licence des composants livrés au navigateur (2026-11-16)

Lot `licences-tierces-bundle` (carnet, file D, ordre 83, après `licence-mention-droits`). Le minificateur de Next retire tous les commentaires de licence du bundle : aucune mention de droits ne partait avec le code servi (examen : `docs/claude/propositions/2026-11-14-orchestration-5-licence/examen-bundle-navigateur.md`).

- `web/scripts/licences-tierces.mjs` : plugin webpack branché sur la seule compilation client de `next build` (`web/next.config.mjs`, build de production seulement). Il lit les modules réellement émis dans les morceaux (modules concaténés, morceaux asynchrones et paquets vendus par Next sous `next/dist/compiled/` compris), ajoute le runtime webpack et Tailwind CSS (son preflight part dans le CSS), et écrit `web/public/licences-tierces.txt`, servi à `/licences-tierces.txt` : pour chaque composant, sa licence déclarée, ses fichiers de licence et NOTICE tels qu'il les fournit.
- Composant sans fichier de licence (next-auth, victory-vendor, react-remove-scroll-bar) : texte type de sa licence déclarée, MIT ou ISC seulement, avec la mention de droits tirée de son champ `author`.
- Le build rougit, sans écrire le fichier : sur une licence sans fichier autre que MIT ou ISC, ou sans licence déclarée ; sur du code vendu sous `dist/compiled/` sans manifeste propre (il serait attribué à tort à son hôte) ; sur du code (`.js`, `.mjs`, `.wasm`) servi sous `static/` hors des morceaux et inconnu.
- Non couverts, et dits en fin de fichier : le fichier de polyfills de Next (core-js et d'autres) et les polices de `next/font` (OFL-1.1). Lot de suite au carnet : `licences-hors-graphe`.
- Banc `web/src/lib/licencesTierces.test.ts` : une vraie compilation webpack (celle de Next) en mode production sur des paquets de fixture, huit cas. Mutation vérifiée : sans l'expansion des modules concaténés, le banc rougit.
- Verrou de `next.config` (`web/src/lib/bio-parcours/resolutionImports.guard.test.ts`) : la clé `webpack` y est admise nommément. Son texte exact est exigé, et, évaluée sur les compilations client, serveur et edge, elle ne fait qu'ajouter ce plugin sur le client en production. Le plugin est figé par son empreinte, et son rappel ne touche que `processAssets`.
- Le fichier généré n'est pas suivi par Git (`web/.gitignore`). Pas d'écran, aucune migration, aucun drapeau.
